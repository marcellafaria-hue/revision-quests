# The Revision Post

A revision game for Grade 7 E.L.A. (3rd trimester): conditionals and I wish, verb patterns, possessives and pronouns, linking words, the formal letter, *Address Unknown* and women writers.

## Put it online with GitHub Pages

1. Create a new **public** repository on GitHub (for example `revision-post`).
2. Click **Add file → Upload files** and upload `index.html` (and this README). Click **Commit changes**.
3. Go to **Settings → Pages**. Under **Branch**, choose `main` and `/ (root)`, then click **Save**.
4. Wait 1–2 minutes. The game will be at `https://YOUR-USERNAME.github.io/revision-post/`.

Students' names and best scores are saved only in their own browser.
