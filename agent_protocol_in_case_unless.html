Agent Protocol: In Case & Unless

A solo weekend mission to sharpen two tricky structures: in case (preparing now for something that might happen later) and unless / as long as / provided / providing (talking about conditions). Complete all briefings to finish the mission.

🎒 Field Manual — quick reference

  • in case something happens = because it's possible it will happen. You act now, before you know.
    I'll take a map in case I get lost.
  • in case of + noun = used on signs/notices. In case of fire, use the stairs.
  • No will after in case, unless, as long as, provided or providing — use a present tense even for the future.
  • unless = except if. You can't go in unless you're a member.
  • as long as / so long as / provided (that) / providing (that) = if, on condition that. You can borrow my car as long as you drive carefully.
